# Squeakly (뽀득)

뭘 지우는지 다 보여 주고 지우는 맥 정리 앱. 개발하다 쌓이는 캐시·개발도구 찌꺼기(Xcode, Docker, node_modules, 시뮬레이터 등)까지 찾아 준다. 한국어 맥에서는 "뽀득", 그 밖의 언어에서는 "Squeakly"로 보인다. 예전 이름은 Sweeper.
(소스는 비공개, 이 저장소에는 배포 파일과 소개 페이지만 있다)

- 소개 페이지: https://dev-fath.github.io/Sweeper-releases/ · English: https://dev-fath.github.io/Sweeper-releases/en/
- 내려받기: [최신 릴리스](https://github.com/dev-fath/Sweeper-releases/releases/latest)의 `Squeakly-<버전>.dmg`

## 설치

1. DMG를 열고 앱을 Applications 폴더로 끌어다 놓는다.
2. 애플 공증을 받지 않은 앱이라 처음 한 번은 직접 허용해야 한다: 실행 → 경고가 뜨면 **완료** → **시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"**.
3. 휴지통·메일 첨부파일까지 정리하려면 같은 화면의 **전체 디스크 접근 권한**에서 앱을 허용한다.

예전 Sweeper 를 쓰고 있었다면 Applications 폴더의 `Sweeper` 를 `Squeakly` 로 이름만 바꾸면 된다(업데이트는 계속 받는다).

macOS 14 이상, Apple Silicon·Intel 모두 지원. 업데이트는 앱이 알아서 확인한다.
